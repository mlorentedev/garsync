# Lessons Learned

> **Moved.** Lessons are now one file each under [`docs/lessons/`](lessons/), so a session
> can load one lesson without loading the corpus. This file used to carry the same entries a second
> time, from before the split — that duplication is retired here.
>
> **Writing a new lesson? Do NOT append here.** Create
> `docs/lessons/lesson-NNN-<slug>.md` at the next free number and run `dotf lessons fmt`. CI checks
> the format and numbering with `dotf lessons fmt --check`, and
> [dotf](https://github.com/mlorentedev/dotfiles) renders an index with `dotf lessons index`.
> Appending to this file recreates the monolith on top of the pointer.
