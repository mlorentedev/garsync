# Lessons Learned

> **Moved.** Lessons are now one file each under [`docs/lessons/`](lessons/_index.md), so a session
> can load the index without loading the corpus. This file used to carry the same entries a second
> time, from before the split — that duplication is retired here.
>
> **Writing a new lesson? Do NOT append here.** Create
> `docs/lessons/lesson-NNN-<slug>.md` at the next free number and add its row to
> [`docs/lessons/_index.md`](lessons/_index.md). Both halves are mandatory and guarded by
> `scripts/check-lessons.sh` (numbering collisions, missing rows, rows pointing nowhere). Appending
> to this file recreates the monolith on top of the pointer.
>
> **Canonical index:** [lessons/_index.md](lessons/_index.md)
